# Pousada JJ • Website Institucional

Aplicação web desenvolvida para a **Pousada JJ**, localizada em Oliveira dos Brejinhos - BA, com foco em presença digital, experiência do usuário e geração de reservas via WhatsApp.

O projeto foi criado para atender uma necessidade real de negócio: modernizar a divulgação da pousada e facilitar o contato direto com clientes através de uma interface responsiva, rápida e otimizada.

# 📖 Sobre o projeto

A aplicação funciona como uma landing page institucional moderna, desenvolvida para apresentar os serviços da pousada de forma clara e profissional.

Além da parte visual, o projeto foi estruturado pensando em:

- conversão de visitantes em contatos
- navegação intuitiva
- carregamento rápido
- experiência responsiva
- organização escalável do código

O site conta com integração estratégica com WhatsApp para acelerar reservas e reduzir fricção no contato com clientes.

# 🚀 Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/JoaoFlavio0/pousadaJJ-site.git
```

Acesse a pasta do projeto:

```bash
cd pousadaJJ-site
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

A aplicação estará disponível em:

```bash
http://localhost:3000
```
